# Banking Fraud Detection System Using SQL

## 📌 Project Overview

The **Banking Fraud Detection System** is a SQL-based database project designed to manage banking information and support the analysis of financial transactions. It demonstrates database creation, table relationships, data management, and SQL query analysis.

This project uses **MySQL** to organize banking data and practice real-world database and data analysis skills.

## 🎯 Project Objectives

- Design and manage a relational banking database.
- Store and retrieve customer and account information.
- Analyze banking transactions using SQL queries.
- Practice primary keys and foreign key relationships.
- Explore transaction records to support fraud-related analysis.
- Improve SQL skills for Data Analyst job opportunities.

## 🛠️ Technologies Used

- **Database:** MySQL
- **SQL Tool:** MySQL Workbench
- **Version Control:** Git and GitHub

## 🗂️ Database Tables

The project includes the following banking-related tables:

| Table Name | Purpose |
|---|---|
| `customers` | Stores customer information |
| `accounts` | Maintains customer account details |
| `transactions` | Stores transaction records |
| `fraud_alerts` | Records fraud-related alerts |
| `beneficiaries` | Stores beneficiary details |
| `login_logs` | Maintains customer login records |
| `cards` | Stores banking card information |
| `loans` | Maintains loan information |
| `branches` | Stores bank branch details |
| `employees` | Maintains employee information |

## 💡 SQL Concepts Practiced

- Database and table creation
- `CREATE`, `INSERT`, `SELECT`, `UPDATE`, and `DELETE`
- Primary keys and foreign keys
- `WHERE`, `ORDER BY`, and `GROUP BY`
- Aggregate functions such as `SUM()`, `COUNT()`, and `AVG()`
- `HAVING` clause
- Joins
- Subqueries
- `CASE` statements
- Window functions such as `RANK()` and `DENSE_RANK()`
- Banking data analysis and fraud-related queries

*The concepts listed above describe the project’s intended learning and analysis scope; use only the concepts implemented in your final SQL files.*

## 🚀 How to Run the Project

1. Install and open MySQL Workbench.
2. Connect to your MySQL server.
3. Open the project `.sql` file.
4. Execute the database and table creation statements.
5. Insert the required data.
6. Run the analysis queries.
7. Review the query results in MySQL Workbench.

**Important:** Execute the SQL statements in the correct order, especially database creation, table creation, data insertion, and analysis queries.
